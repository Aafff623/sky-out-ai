|                              | 旨在设计并实现一款外卖订餐管理系统。本系统使用Java语言进行开发，后端使用spring boot框架，前端使用Vue框架搭建，数据库使用MySQL，redis。通过本课题的研究与实现，预期可以得到一款功能完善、性能优越的外卖订餐管理系统。本系统主要分为管理后台和小程序端应用                                                                                                                                |
